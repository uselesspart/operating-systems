# Лабораторная работа №2 — локальный чат

Вариант 13 (15 баллов). Хост с интерфейсом Qt запускает одного консольного клиента через `fork()`. Способы связи: POSIX-очереди сообщений, именованные каналы и локальная пара сокетов.

## Сборка

Linux с glibc 2.30+, компилятор C++17, Make, CMake и Qt Widgets. В Ubuntu достаточно пакетов `build-essential cmake qt6-base-dev`.

```bash
make
```

Также можно выполнить `bash build.sh`. Результат: `host_mq`, `host_fifo`, `host_sock`. Промежуточные файлы CMake удаляются.

## Запуск

Из терминала графической сессии запустить один из файлов, например `./host_mq`. Хост откроет окно чата, а дочерний клиент останется в исходном терминале.

- В окне хоста: ввести текст, при необходимости выбрать «Лично клиенту», нажать Enter или «Отправить».
- В консоли клиента: обычная строка — общее сообщение, `/host текст` — личное, `/quit` — выход.

Хост показывает сообщения в порядке принятия. При двух участниках личное и общее сообщение видят обе стороны, но метки различаются. Ожидание межпроцессного ответа ограничено пятью секундами. Если клиент минуту не отправляет сообщений, хост завершает его сигналом SIGKILL. Закрытие окна завершает сессию.

## Проверка

```bash
make test
```

Тесты проверяют для каждого транспорта подключение, обмен, выход, повторный запуск и завершение клиента при тайм-ауте.
