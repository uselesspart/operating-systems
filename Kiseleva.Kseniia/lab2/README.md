# Лабораторная работа №2. Межпроцессное взаимодействие в Linux

**Вариант:** 13  
**Сценарий:** 2 — локальный чат.

## Описание

Программа реализует локальный чат между двумя связанными процессами: Host и Client.

Процесс Host запускается первым и создаёт процесс Client с помощью `fork()`. Для обмена сообщениями используются механизмы межпроцессного взаимодействия Linux.

Реализованы три варианта IPC:

- **MQ** — POSIX очереди сообщений (`mq_open`, `mq_send`, `mq_receive`).
- **FIFO** — именованные каналы (`mkfifo`).
- **SOCK** — локальные сокеты (`socketpair`).

Для синхронизации процессов используются POSIX-семафоры (`sem_init`).

Поддерживаются публичные и личные сообщения, временные метки сообщений, завершение соединения и отключение неактивного клиента.

## Требования

- Linux
- C++20
- GCC
- CMake
- Qt 6 (компонент Widgets)
- POSIX Threads

## Сборка

Из каталога `lab2` выполните один из вариантов:

```bash
./build.sh
```

или:

```bash
make
```

Исполняемые файлы будут созданы в каталоге `build/`:

- `host_mq`
- `host_fifo`
- `host_sock`

## Запуск

```bash
./build/host_mq
```

```bash
./build/host_fifo
```

```bash
./build/host_sock
```

Каждый исполняемый файл запускает Host, который создаёт дочерний процесс Client.

## Очистка

Для удаления результатов сборки выполните:

```bash
make clean
```

## Структура проекта

- `host.cpp` — Host и графический интерфейс чата.
- `client.cpp` — логика Client.
- `connection.h` — общий интерфейс соединения и структуры сообщений.
- `conn_mq.cpp`, `conn_mq.h` — реализация через POSIX очереди сообщений.
- `conn_fifo.cpp`, `conn_fifo.h` — реализация через именованные каналы.
- `conn_sock.cpp`, `conn_sock.h` — реализация через локальные сокеты.
- `CMakeLists.txt` — конфигурация сборки CMake.
- `Makefile` — команды сборки и очистки.
- `build.sh` — скрипт автоматической сборки.
