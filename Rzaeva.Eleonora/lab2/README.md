# Лабораторная работа № 2. Межпроцессное взаимодействие

**Вариант № 1 (10 баллов).** Игра «Волк и семеро козлят», родственная конфигурация «один к одному». Хост запускает одного козлёнка через `fork`, ведёт игру и показывает результаты в окне Qt. Козлёнок отправляет свои броски и получает результат каждого раунда. Реализованы три способа связи — анонимный `mmap`, `shm_open` + `mmap` и `pipe`. Для синхронизации используются локальные семафоры с тайм-аутом в 5 секунд.

## Правила игры

- Волк выбирает число от 1 до 100. Если игрок не отправил число за 3 секунды, программа выбирает его случайно.
- Живой козлёнок случайно выбирает число от 1 до 100. Он прячется, если разница с числом волка не больше 70. Иначе волк его ловит.
- Мёртвый козлёнок случайно выбирает число от 1 до 50. Он воскресает, если разница с числом волка не больше 20.
- Игра заканчивается, если козлёнок остаётся мёртвым по итогам двух раундов подряд. В окне видны оба броска и число спрятавшихся, пойманных и мёртвых козлят.

## Сборка и запуск

Нужны Linux или WSL с поддержкой графических приложений, компилятор C++17, CMake, Make и Qt Widgets. Выполнить из каталога `Rzaeva.Eleonora/lab2`:

```bash
make
./host_mmap
```

Для других способов связи запустить `./host_shm` или `./host_pipe`. В окне ввести число и нажать Enter или кнопку «Сыграть».

`make clean` удаляет исполняемые файлы.

## Тесты

Из каталога `Rzaeva.Eleonora/lab2` выполнить:

```bash
make test
```

Команда собирает проект и запускает 9 тестов. Для каждого из трёх способов связи проверяются правила игры, обмен данными между процессами и тайм-аут в 5 секунд.
