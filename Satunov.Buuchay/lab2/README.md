# Лаба 2
Вариант 13

Локальный чат для обмена сообщениями между двумя родственными процессами: хостом и клиентом.

Хост создаёт дочерний процесс через fork(). Хост работает с графическим интерфейсом Qt6 Widgets, клиент — через терминал.

Приложение поддерживает:
- Общие и личные сообщения.
- Отображение истории сообщений в хронологическом порядке.
- Три механизма межпроцессного взаимодействия: POSIX Message Queue, FIFO и Unix Domain Socket.
- Синхронизацию процессов через локальные POSIX-семафоры.
- Отображение состояния подключения и ошибок в интерфейсе хоста.

Если клиент не отправляет сообщения в течение 60 секунд, хост завершает его сигналом SIGKILL.

## Платформа

Программа предназначена для Linux и использует:
- fork() и waitpid() для создания и контроля дочернего процесса;
- sem_init(), sem_post() и sem_timedwait() для синхронизации;
- mmap() для размещения семафоров в общей памяти;
- mq_open(), mq_timedsend() и mq_timedreceive() для очередей сообщений;
- mkfifo(), read() и write() для именованных каналов;
- socket(), bind(), listen(), accept4() и connect() для Unix-сокетов;
- SIGKILL для завершения неактивного клиента;
- Qt6 Widgets для графического интерфейса хоста.

Ожидание операций IPC и семафоров ограничено 5 секундами.

В Windows запуск возможен через WSL 2 с поддержкой графических приложений или виртуальную машину с Linux.

## Сборка

```bash
./build.sh
```

Также доступна сборка через Makefile:

```bash
make
```

Сборка выполняется с использованием C++20 и параметрами:

```text
-std=c++20 -Wall -Wextra -Werror
```

Для сборки необходимы CMake, компилятор C++20 и Qt6 Widgets.

Создаются три исполняемых файла:
- host_mq — очереди сообщений;
- host_fifo — именованные каналы;
- host_sock — Unix-сокеты.

## Запуск

Запуск через POSIX Message Queue:

```bash
./build/host_mq
```

Запуск через FIFO:

```bash
./build/host_fifo
```

Запуск через Unix Domain Socket:

```bash
./build/host_sock
```

При запуске хост создаёт дочерний процесс, устанавливает IPC-соединение и открывает графическое окно Qt.

Сообщения хоста отправляются из графического интерфейса. Для отправки можно выбрать общий или личный тип сообщения.

Клиент работает в терминале. Обычный ввод отправляет общее сообщение.

Отправить личное сообщение:

```text
/private Привет!
```

Завершить клиент:

```text
/quit
```

Если клиент не отправляет сообщения более 60 секунд, хост принудительно завершает его через SIGKILL.

При завершении работы освобождаются используемые IPC-ресурсы.

## Тесты

```bash
make test
```

Автоматические тесты проверяют:
- Сериализацию и проверку корректности сообщений.
- Хронологический порядок истории.
- Создание и завершение дочернего процесса.
- Синхронизацию семафорами и тайм-ауты.
- Двусторонний обмен через POSIX Message Queue.
- Двусторонний обмен через FIFO.
- Двусторонний обмен через Unix Domain Socket.
- Общие и личные сообщения.
- Отслеживание неактивности клиента.
- Сквозной обмен между хостом и клиентом для каждого механизма IPC.

Отдельно можно запустить сквозные тесты:

```bash
./build/host_mq --self-test
./build/host_fifo --self-test
./build/host_sock --self-test
```

Они проверяют создание процессов, установление соединения и обмен сообщениями без запуска графического интерфейса.
