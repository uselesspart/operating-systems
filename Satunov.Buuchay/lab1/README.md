# Лаба 1
Вариант 18

Демон читает конфигурационный файл произвольного размера. Каждая строка имеет формат:
folder depth. Демон периодически очищает файлы в подпапках folder до указанной глубины. Сама корневая папка, каталоги и содержимое глубже заданной глубины сохраняются.

## Платформа

Программа предназначена для Linux и использует:
- fork() и setsid() для демонизации;
- /proc для проверки процесса из PID-файла;
- SIGHUP и SIGTERM для управления;
- openlog(), syslog() и closelog();
- chdir("/") и /dev/null при настройке демона.
  
В Windows запуск возможен через WSL 2, Docker или виртуальную машину с Linux.

## Сборка 

```bash
./build.sh
```

Сборка выполняется с параметрами:

```
-std=c++20 -Wall -Wextra -Werror -pedantic -pthread
```

## Запуск
```bash
./daemon config.example
```
После запуска процесс уходит в фон.

Прмер конфига:

```
/tmp/os_lab1_demo/tree 2
```

Перечитать конфиги:
```bash
kill -HUP "$(cat /tmp/os_lab1_daemon.pid)"
```

Завершить демон:
```bash
kill -TERM "$(cat /tmp/os_lab1_daemon.pid)"
```

Демон защищён от повторного запуска: новый экземпляр находит старый процесс через PID-файл и /proc, отправляет ему SIGTERM, а затем записывает собственный PID.

Сообщения о запуске, ошибках, перечитывании конфигурации и завершении записываются через openlog, syslog и closelog.

## Тесты
```bash
./test.sh
```

Интеграционные тесты проверяют:
- запуск демона;
- очистку каталогов до заданной глубины;
- перечитывание конфигурации через SIGHUP;
- корректное завершение через SIGTERM;
- удаление PID-файла;
- остановку предыдущего экземпляра при повторном запуске.
