# OS_Autumn_2026


## Задание
Напоминалка. В конфигурационный файл пользователь может добавлять с помощью специального скрипта новые события для напоминания в формате “add_event date time [flag] text”, где flag - необязательное поле, значения “-h -d -w” означают повтор напоминаний каждый час, день, неделю, соответственно. В указанное время демон должен открывать новый терминал и выводить заданный текст.
Интервал срабатывания: 10 секунд.
## Сборка и запуск

```bash
./build.sh
./schedule_daemon
./add_event 2026-10-18 12:00 -d Doctor
kill -TERM $(cat /tmp/schedule_daemon.pid)
```
Формат конфига:

```
add_event YYYY-MM-DD HH:MM [-h|-d|-w] TEXT
```

`add_event` дописывает такую же строку в конфиг и отправляет демону SIGHUP.
