# Lab 2, вариант 13

Локальный чат. Родственные процессы, один к одному.
Типы взаимодействия: mq, fifo, sock.

## Сборка

Нужны cmake и Qt6 (пакет qt6-base-dev).

    ./build.sh

После сборки в папке появятся host_mq, host_fifo и host_sock.

## Запуск

    ./host_sock

Откроется окно хоста. Клиент запускается сам через fork и работает в
том же терминале.

В окне пишем сообщение и жмём "Всем" или "Лично". В терминале у клиента
обычная строка уходит всем, "/p текст" отправляет личное сообщение,
"/q" это выход.

## Как устроено

- conn.h общий интерфейс Conn, в conn_mq.cpp, conn_fifo.cpp и
  conn_sock.cpp его реализации. CMake сам делает host_* для каждого
  файла conn_*.cpp.
- host.cpp создает в общей памяти семафор (sem_init), делает fork и
  ждет от клиента сигнал, что он подключился (не больше 5 секунд).
- chat_session.cpp поток, который читает и пишет сообщения. Только он
  работает с Conn, окно кладет сообщения в очередь.
- chat_window.cpp окно на Qt, сообщения в нем стоят по времени отправки.
- Если клиент молчит больше минуты, хост убивает его через SIGKILL.
  Для проверки время можно поменять: LAB2_IDLE_MS=5000 ./host_sock

## Тесты

    tests/run_tests.sh

Тесты запускают хост без окна (LAB2_NOGUI=1) и проверяют обмен
сообщениями, отключение молчащего клиента и убитого клиента, а также
что после работы не остаются файлы в /tmp.
