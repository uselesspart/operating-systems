# Лабораторная работа 1. Демон

Вариант 10.

Вести в папке 2 протокол содержимого папки 1: дописывать в файл “hist.log” текущее время и список всех файлов и подпапок папки 1.

## Сборка

    ./build.sh

Получается файл build/lab1. Собирается с -Wall -Werror, объектные файлы
скрипт удаляет сам.

## Запуск

    ./build/lab1 конфиг

Конфиг выглядит так:

    # комментарий
    dir1=/home/user/in
    dir2=/home/user/out
    interval=30

Папка dir2 должна уже существовать. Путь к конфигу можно написать
относительный, демон сам запоминает полный.

## Как работает

Демон уходит в фон через fork и setsid. Чтобы не запускалось два экземпляра,
он пишет свой pid в /tmp/lab1_daemon.pid. Если при запуске там лежит pid
живого процесса lab1, ему посылается SIGTERM, и новый демон занимает его
место.

SIGHUP перечитывает конфиг. Если в нём ошибка, демон пишет об этом в журнал
и продолжает со старыми настройками. SIGTERM завершает демона, он пишет
в журнал о выходе и удаляет pid-файл.

Журнал: journalctl -t lab1_daemon

Класс Daemon сделан синглтоном (src/Daemon.cpp), чтение конфига лежит
отдельно в src/Config.cpp.

## Тесты

    tests/run_tests.sh

Скрипт собирает программу, запускает демона во временной папке и проверяет
запуск, pid-файл, сигналы и hist.log.
