# Лабораторная работа 1. Демон

Вариант 7.

Удалять все подпапки папки `dir1`. Файлы, лежащие прямо в `dir1`,
не удаляются. Подпапки удаляются рекурсивно.

## Сборка

    ./build.sh

Получается файл `build/lab1`. Собирается с `-Wall -Werror`,
объектные файлы скрипт удаляет сам.

## Запуск

    ./build/lab1 конфиг

Конфиг:

    # комментарий
    dir1=/home/user/in
    interval=20

`dir1` должен существовать. Путь к конфигу можно указать относительным —
демон сам запоминает полный путь.

## Как работает

Демон уходит в фон через `fork` и `setsid`. Чтобы не запускалось два
экземпляра, он пишет свой pid в `/tmp/lab1_daemon.pid`. Если при запуске
там лежит pid живого процесса `lab1`, ему посылается `SIGTERM`, после
чего новый демон занимает его место.

`SIGHUP` перечитывает конфиг. Если в нём ошибка, демон пишет об этом
в журнал и продолжает со старыми настройками. `SIGTERM` завершает
демона, он пишет в журнал о выходе и удаляет pid-файл.

Каждые `interval` секунд демон удаляет все подкаталоги `dir1`.
Ошибки чтения каталога и ошибки удаления регистрируются в syslog.

Журнал:

    journalctl -t lab1_daemon

Класс `Daemon` — синглтон (`src/Daemon.cpp`), чтение конфига —
в `src/Config.cpp`.

## Быстрая проверка

    mkdir -p /tmp/in/sub/deep
    touch /tmp/in/keep.txt
    printf 'dir1=/tmp/in\ninterval=20\n' > /tmp/lab1.conf
    ./build/lab1 /tmp/lab1.conf
    sleep 1
    test ! -e /tmp/in/sub
    test -f /tmp/in/keep.txt
