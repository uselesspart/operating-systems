# Лабораторная работа 1 — вариант 14

Linux-демон на C++17. Конфигурация содержит интервал и произвольное число правил `folder ignfile`.
Если в `folder` нет файла `ignfile`, содержимое каталога удаляется; если файл есть — каталог не изменяется.

## Реализовано

- демонизация через `fork()` + `setsid()` + второй `fork()`;
- singleton-класс `Daemon`;
- абсолютный путь к конфигу сохраняется до `chdir("/")`;
- интервал задаётся в конфиге (`interval N`), для варианта 14 в примере — 20 секунд;
- произвольное число правил `folder ignfile`;
- `SIGHUP` перечитывает конфигурацию без перезапуска;
- `SIGTERM` пишет сообщение в syslog и корректно завершает демон;
- логирование через `openlog`, `syslog`, `closelog`;
- pid-файл в `/tmp/os_lab1_variant14_<uid>.pid`;
- повторный запуск проверяет старый PID через `/proc`, отправляет старому процессу `SIGTERM`, ждёт завершения и затем записывает новый PID;
- сборка через `build.sh` с `-Wall -Werror`, промежуточные файлы удаляются;
- автоматические интеграционные тесты.

## Сборка

```bash
chmod +x build.sh run_tests.sh tests/run_tests.sh
./build.sh
```

Результат: `./daemon14`.

## Конфигурация

Пример `config.example`:

```text
interval 20
demo/folder_a dont.erase
demo/folder_b keep.me
```

Относительные пути считаются относительно каталога, где находится конфигурационный файл.

## Запуск

```bash
./daemon14 config.example
```

PID:

```bash
cat /tmp/os_lab1_variant14_$(id -u).pid
```

Перечитать конфиг:

```bash
kill -HUP $(cat /tmp/os_lab1_variant14_$(id -u).pid)
```

Завершить:

```bash
kill -TERM $(cat /tmp/os_lab1_variant14_$(id -u).pid)
```

Журнал:

```bash
journalctl -t os_lab1_v14 --since "10 minutes ago" --no-pager
```

## Тесты

```bash
./run_tests.sh
```

Тесты автоматически проверяют:

1. сборку и очистку промежуточных файлов;
2. запуск демона и создание pid-файла;
3. очистку каталога без `ignfile`;
4. сохранение каталога с `ignfile`;
5. периодическое повторение обработки;
6. перечитывание конфига по `SIGHUP` без смены PID;
7. замену старого экземпляра при повторном запуске через pid-файл и `/proc`;
8. завершение по `SIGTERM` и удаление pid-файла.

Для тестов используется временный pid-файл через переменную окружения `OS_LAB1_PID_FILE`, чтобы не мешать обычному запущенному экземпляру.
