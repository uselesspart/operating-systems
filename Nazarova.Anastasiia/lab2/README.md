# Лабораторная работа 2

Вариант 20. Чат на C++ и Qt с независимыми клиентами. Хост обслуживает каждого клиента в отдельном потоке. Доступны общие и личные сообщения.

Для сборки нужны Linux с ядром 5.3 или новее, g++, Make, CMake и Qt 6.3 или новее. Для тестов также нужен Python 3. В Ubuntu зависимости устанавливаются командой:

```sh
sudo apt install build-essential cmake qt6-base-dev python3
```

Сборка:

```sh
make
```

Сначала запускается хост. Его PID виден в окне. Клиент запускается из другого терминала с этим PID:

```sh
./host_pipe
./client_pipe PID_хоста
```

Для FIFO используются `host_fifo` и `client_fifo`, для сокетов `host_sock` и `client_sock`. Хост и клиенты запускаются от одного пользователя с одинаковой настройкой временного каталога. В версии pipe клиенты открывают каналы хоста через `/proc/PID/fd`.

В окне выбирается адресат или «Всем». Сообщения отображаются по времени отправки. Через минуту без отправленных сообщений клиент завершается сигналом SIGKILL. Ожидание подключения и обмена ограничено пятью секундами. При закрытии хоста клиенты завершают работу, временные файлы и семафоры удаляются.

Проверка всех трёх способов связи и интерфейса:

```sh
make test
```

Тесты проверяют доставку сообщений, личную переписку, несколько клиентов, тайм-ауты, отключение за бездействие и очистку ресурсов. Проверка минутного тайм-аута занимает не меньше минуты.
