# Лабораторная работа №2. Локальный сетевой чат (вариант 13)

Хост и клиент обмениваются общими и личными сообщениями через межпроцессное взаимодействие в Linux. Общие сообщения видны обоим участникам, личные — отправителю и адресату. Сообщения отображаются в порядке времени отправления.

**Конфигурация:** родственные процессы, один к одному. Хост создаёт одного клиента с помощью `fork()`.

**Типы взаимодействия:** очереди сообщений (`mq_open`, `mq`), именованные каналы (`mkfifo`, `fifo`) и сокеты (`socket`, `sock`).

**Язык:** C++20. **ОС:** Linux. **Графический интерфейс:** Qt 6 Widgets.

## Сборка

Требуются компилятор с поддержкой C++20, CMake 3.21 или новее, Make и Qt 6 Widgets.

Установка зависимостей в Ubuntu:

```bash
sudo apt update
sudo apt install -y build-essential cmake qt6-base-dev
```

Сборка всех трёх вариантов:

```bash
make
```

`Makefile` вызывает `build.sh`, который использует CMake с флагами `-Wall -Werror`. Во время сборки промежуточные файлы создаются в каталоге `build/`, который автоматически удаляется после сборки или тестов. Исполняемые файлы `host_mq`, `host_fifo` и `host_sock` остаются в корне лабораторной работы.

Очистка результатов сборки:

```bash
make clean
```

## Запуск и использование

Запустите один из вариантов из каталога `lab2`:

```bash
./host_mq
./host_fifo
./host_sock
```

Каждая команда запускается отдельно. Программа создаёт дочерний процесс и открывает два окна Qt: «Чат — Хост» и «Чат — Клиент».

В каждом окне можно выбрать получателя («Всем» или лично собеседнику), ввести сообщение и отправить его кнопкой или клавишей Enter. Личные сообщения выделяются цветом. В интерфейсе также отображаются подключение, отключение и ошибки связи.

Если клиент не отправляет сообщений более 60 секунд, хост завершает его сигналом `SIGKILL`. Для самого хоста это ограничение не действует. Программа завершается при закрытии окон или по `Ctrl + C` в терминале.

## Устройство программы

| Модуль | Назначение |
|---|---|
| `src/host.cpp` | Запуск хоста и дочернего процесса, обработка сигналов и завершение работы |
| `src/chat_window.h`, `src/chat_window.cpp` | Окна Qt, переписка, статусы и контроль неактивности клиента |
| `src/message.h` | Формат сообщений, время отправки и проверка адресата |
| `src/connection.h`, `src/connection.cpp` | Общий интерфейс соединения и синхронизация процессов |
| `src/conn_mq.cpp` | Обмен через очереди сообщений POSIX |
| `src/conn_fifo.cpp` | Обмен через именованные каналы FIFO |
| `src/conn_sock.cpp` | Обмен через локальную пару сокетов |
| `CMakeLists.txt`, `build.sh`, `Makefile` | Автоматическая сборка всех вариантов |
| `tests/` | Автоматические тесты протокола и механизмов взаимодействия |

Для синхронизации применяются локальные семафоры `sem_init`, размещённые в общей анонимной памяти `mmap`. Ожидание при установлении соединения ограничено 5 секундами. Обмен сообщениями выполняется без блокировки графического интерфейса.

Очереди MQ и каналы FIFO создаются и открываются после `fork()`. При завершении хост удаляет созданные очереди и FIFO-файлы. Для сокетов используется `socketpair`.

## Тестирование

Запуск всех тестов:

```bash
make test
```

Тест `message` проверяет формат сообщений, адресацию и ограничения длины. Тесты `transport_mq`, `transport_fifo` и `transport_sock` проверяют передачу сообщений в обе стороны, порядок и целостность данных, переполнение канала, тайм-ауты подключения, завершение собеседника и освобождение ресурсов. Для FIFO дополнительно проверяется сборка сообщения, прочитанного частями.

Тесты используют реальные процессы и запускаются без `sudo`. Работа окон Qt и отключение клиента после 60 секунд дополнительно проверяются вручную.
